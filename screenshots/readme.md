# Скріншоти лабораторної роботи

У цій папці поки немає файлів-зображень. Наявний браузерний сеанс GitHub показав інший профіль, тому зміни не вносилися. Netlify не підключений. Прямий перегляд локального файлу в браузері цього середовища заблокований політикою робочого простору. Щоб не видавати підроблені зображення за докази, потрібні скріншоти будуть додані після входу до правильного GitHub-акаунта та реального розгортання на Netlify.

Обов’язкові скріншоти за методичкою: код `lab2/index.html` у редакторі; репозиторій `ip_labs` із файлами; головна сторінка на публічному Netlify HTTPS-посиланні.
