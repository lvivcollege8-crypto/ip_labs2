# Практична робота №3 — World Trivia

Адаптивний односторінковий сайт компанії World Trivia, виконаний на HTML5, CSS3 і JavaScript без сторонніх бібліотек.

## Структура

- `index.html` — семантична сторінка з секціями Home, Trivia, Categories, Scores, Subscribe і Contact.
- `css/style.css` — оформлення, Flexbox, таблиця, адаптивні правила, focus/hover, pulse-анімація та режим reduced motion.
- `js/main.js` — взаємодія головоломки дня і демонстраційна клієнтська перевірка контактної форми.
- `assets/` — локальні SVG-ілюстрації та favicon.

## Запуск

Відкрий `index.html` у браузері або запусти локальний статичний сервер у теці `pw3`.

## Функціональні примітки

Головоломка дня інтерактивна та перевіряє відповідь у браузері. Контактна форма перевіряє обов'язкові поля клієнтськими засобами й показує демонстраційний статус; серверного надсилання даних немає. Таблиця балів є демонстраційною.
