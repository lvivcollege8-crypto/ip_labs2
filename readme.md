# Лабораторні роботи — Програмування в Internet

Навчальний адаптивний сайт студента Чонки Максима Андрійовича (ІП-41), створений для лабораторної роботи №2.

## Структура

- `index.html` — головна сторінка з переліком робіт.
- `lab1/index.html` — чесна сторінка-заготовка; вміст справжньої лабораторної №1 не вигадувався.
- `lab2/index.html` — сторінка лабораторної №2.
- `assets/style.css` — спільні адаптивні стилі.
- `screenshots/` — каталог для фактичних знімків. Скріншоти GitHub і Netlify з’являться після авторизації та публікації.

## Локальний запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер із кореня проєкту:

```sh
python3 -m http.server 8000
```

Потім перейдіть на `http://localhost:8000`.

## Навігація

Головне меню побудоване через `ul`, а вкладені пункти лабораторних — через `ol`. Для Lab3 показано «Незабаром» без посилання. На всіх сторінках використані `header`, `nav`, `main`, `article`, `section`, `aside` і `footer`.

## Публікація

Після створення приватного GitHub-репозиторію `ip_labs` проєкт можна підключити в Netlify як статичний сайт без build-команди та без каталогу публікації або з каталогом `.`. Автоматичний deploy треба ввімкнути для основної гілки.

Поточний статус GitHub/Netlify: локальний коміт створено; віддалений репозиторій та публікація ще не створені. Для цього потрібен доступ до створення приватного репозиторію саме в акаунті власника та авторизація Netlify.
