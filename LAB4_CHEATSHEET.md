# Шпаргалка до захисту лабораторної №4

## Що зроблено

У `lab4/index.html` створено адаптивну анкету студента. Для логічних груп полів використано `section`, `fieldset` та `legend`; кожен елемент введення має зрозумілу мітку.

Форма містить ПІБ, email, пароль для демонстрації, вік, дату народження, стать, мови, країну, список предметів із множинним вибором, повзунок інтересу, текстову область навичок, файл, колір і час.

## Як працює форма

HTML5 перевіряє обов’язковість полів, формат email, межі віку, а також мінімальну й максимальну довжину тексту. JavaScript оновлює значення повзунка та показує повідомлення після успішної перевірки браузером.

Це статичний навчальний сайт без сервера. Обробник JavaScript зупиняє відправлення форми: реальні персональні дані та пароль ніде не зберігаються. Файл вибирається у браузері, але не завантажується на сервер. Для справжнього приймання форми потрібні серверний endpoint та обробник файлів.

## Семантичні й формові теги

- `header`, `nav`, `main`, `article`, `section`, `aside`, `footer` — структурують сторінку за призначенням блоків.
- `form` — об’єднує поля та керує надсиланням.
- `label` — пов’язує назву з полем.
- `fieldset` і `legend` — логічно групують поля та дають групі назву.
- `input` з типами `text`, `email`, `password`, `number`, `date`, `radio`, `checkbox`, `range`, `file`, `color`, `time`; також `select`, `textarea`, `button`.

## Git: основні команди

```bash
git branch lab4
git switch lab4
git add lab4/index.html assets/lab4.css assets/lab4.js
git commit -m "Додано лабораторну роботу 4"
git switch main
git merge lab4
git push origin main
```

Для цієї роботи віддалену гілку `lab4` створено в GitHub, а її зміни об’єднано в актуальну головну гілку `main`. У методичці наведено `master`, але в цьому репозиторії головна гілка називається `main`.

## GitHub і Netlify

GitHub зберігає код та історію змін. Netlify автоматично публікує зміни з гілки `main` після оновлення репозиторію. Сторінка лабораторної: <https://bespoke-dango-45b158.netlify.app/lab4/>.

## Відповіді на контрольні питання

1. **Семантичні теги:** `header`, `nav`, `main`, `article`, `section`, `aside`, `footer`.
2. **Елементи форми:** текст, email, пароль, число, дата, радіокнопки, прапорці, списки `select` і `select multiple`, range, textarea, file, color, time та submit.
3. **Гілка lab4:** створення і перемикання на гілку, `git add`, `git commit`, повернення на `main`, `git merge lab4`, `git push origin main`. У сучасному Git для перемикання можна використовувати `git switch` замість `git checkout`.
4. **`action`:** задає адресу обробника, куди браузер надсилає дані форми. У цій демонстрації JavaScript зупиняє надсилання, серверного обробника немає.
5. **Валідація:** `required`, тип `email`, обмеження `min`/`max`, `minlength`/`maxlength`, а також перевірка введення браузером.
6. **Завантаження файлів:** `input type="file"`, `method="post"` та `enctype="multipart/form-data"`; потрібен серверний обробник, який приймає файл і перевіряє його.
