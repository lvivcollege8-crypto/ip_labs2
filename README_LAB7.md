# Лабораторна робота №7 — адаптивна сторінка новин

Варіант №2 обрано за порядковим номером студента у журналі — 20. У сторінці реалізовано `header#hero_container` за допомогою Flexbox і блок `div.main-container` із CSS Grid.

## Що виконано

- Створено `lab7/index.html` та `lab7/css/styles.css`.
- Flexbox використано для університетської панелі та hero-заголовка.
- CSS Grid формує картки новин: 1 колонка до 767 px, 2 колонки для 768–1023 px, 4 колонки від 1024 px.
- Додано переходи для карток і посилань, keyframe-анімації появи блоків та `prefers-reduced-motion`.
- На головній сторінці додано пункт меню й картку Lab7.
- Заголовки й посилання ведуть на відповідні публікації lpnu.ua.
