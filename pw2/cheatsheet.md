# Коротка шпаргалка до практичної №2

- Відступи між шарами у Figma Design Mode: наведіть курсор, затисніть `Alt`.
- Вибрати внутрішній шар: `Ctrl` + клік (Deep Select).
- Типографіка: права панель `Design` → `Typography`.
- HEX-колір: права панель `Design` → `Fill`; тінь: `Effects`.
- Експорт логотипів та іконок: SVG; фотографій: JPG/PNG у масштабі 2x.
- Auto Layout `Gap` відповідає властивості CSS `gap`.
- Flexbox: `justify-content` розподіляє елементи по головній осі, `align-items` — по поперечній.
- `padding` — відстань усередині меж елемента; `margin` — зовні.
- У цій роботі використано парний варіант Pets (номер у списку 20).
