# Практична робота №2 — Figma та верстка секції Hero

Односторінкова адаптивна верстка варіанта **Pets** для 20-го номера у списку. Сторінку створено за наданим `Landing Page UI Kit.fig`; шрифт Poppins підключено з Google Fonts. У коді використано семантичні HTML-елементи, Flexbox/Grid, адаптивні стилі та мобільне меню.

## Структура

- `index.html` — сторінка Petworld з Hero, блоками переваг і футером.
- `css/style.css` — стилі, адаптивність та стани доступності.
- `assets/menu.js` — відкриття й закриття мобільної навігації.
- `assets/paw.svg` — векторний знак і favicon.
- `assets/images/` — локальні графічні ресурси з наданого Figma-макета.
- `screenshots/` — знімки фактичного рендерингу сайту після перевірки.

## Запуск

Відкрити `index.html` у браузері або опублікувати вміст папки `pw2` на статичному хостингу. Зображення локальні; зовнішнє мережеве завантаження потрібне лише для Google Font Poppins.

## Нотатка про макет

Сторінку верстали за варіантом Pets для фрейму `Pets 1280px`, а не за непарним варіантом Home. Окрему копію Figma-файлу до репозиторію не додано; зображення витягнуто з прикріпленого `.fig`.
