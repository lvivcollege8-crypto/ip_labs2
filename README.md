# ip_labs2

Навчальний вебпроєкт з дисципліни «Програмування в Internet» для Чонки Максима Андрійовича, група ІП-41.

## Структура

- `index.html` — головна сторінка з меню лабораторних.
- `lab1/index.html` — чесно позначена заготовка лабораторної №1.
- `lab2/index.html` — лабораторна №2 про створення меню.
- `lab3/index.html` — сторінка лабораторної №3 з графікою й мультимедіа.
- `lab4/index.html` — адаптивна анкета студента з вбудованою HTML5-валідацією.
- `lab3/map.html` — локальний приклад інтерактивної карти; сторінка Lab3 вбудовує Google My Maps.
- `assets/style.css` — спільні адаптивні стилі.
- `assets/lab4.css`, `assets/lab4.js` — стилі й безпечна локальна взаємодія форми.
- `assets/college-logo.jpg`, `assets/ukraine-flag-video.mp4`, `assets/student-audio.m4a` — ресурси Lab3. MP4 — наданий ролик до Дня Державного прапора України.
- `LAB3_CHEATSHEET.md` і `LAB4_CHEATSHEET.md` — шпаргалки до захисту.

## Лабораторна робота №4

Форма містить текст, email, password, number, date, radio, checkbox, select, multiselect, range, textarea, file, color, time та submit. Вбудована перевірка браузера працює локально; форма не передає особисті дані й пароль на сервер. Для реального завантаження резюме потрібен серверний обробник.

Пряма адреса анкети: https://bespoke-dango-45b158.netlify.app/lab4/.

## Карта та відео

Сторінка Lab3 вбудовує карту Google My Maps «Музеї та театри Львова» з двома шарами по п'ять об'єктів. MP4-блок відтворює наданий ролик із прапором України. Окремий YouTube iframe наразі демонструє ролик офіційного каналу коледжу; щоб виконати вимогу саме про власну трансляцію, потрібно опублікувати власне відео на YouTube та замінити адресу iframe.

Справжній скриншот карти на опублікованому сайті міститься у `screenshots/08_netlify_lab3_google_mymaps.png`.

## Локальний запуск

У корені проєкту запусти `python3 -m http.server 8000` і відкрий `http://localhost:8000`. Потрібен доступ до Інтернету для зовнішніх відео/карт.
