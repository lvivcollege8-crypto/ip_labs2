# ip_labs2

Навчальний вебпроєкт з дисципліни «Програмування в Internet» для Чонки Максима Андрійовича, група ІП-41, 2026 рік.

## Структура

- `index.html` — головна сторінка та меню лабораторних.
- `lab1/`–`lab7/` — сторінки лабораторних робіт; лабораторна №1 позначена як заготовка, оскільки її файлів не було надано.
- `assets/` — спільні стилі й медіафайли.
- `lab3/map.html` — локальний приклад карти; у Lab3 вбудована Google My Maps.
- `lab4/`, `lab5/`, `lab6/`, `lab7/` — наступні лабораторні роботи.

## Лабораторна №7

Відтворено адаптивний блок новин із використанням Flexbox для `header#hero_container` і CSS Grid для `div.main-container`. Сітка має 1 колонку на мобільному екрані (до 767 px), 2 на планшеті (768–1023 px) і 4 на настільному екрані (від 1024 px). Додано CSS transitions, keyframe animations і підтримку `prefers-reduced-motion`. Варіант №2 визначено за порядковим номером у журналі (20).

## Локальний запуск

У корені проєкту виконайте `python3 -m http.server 8000` і відкрийте `http://localhost:8000/`. Для зовнішніх відео, карти й новинних посилань потрібен Інтернет.
